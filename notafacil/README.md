# NotaFácil

Aplicación web para registrar estudiantes y sus notas de un curso, calcular su promedio ponderado y ver su estado (Destacado, Aprobado o Desaprobado).

## Tecnologías

- React 18
- Vite 5
- localStorage del navegador (persistencia de datos)

## Funcionalidades

- Registrar, editar y eliminar estudiantes.
- Calcular el promedio: T1 30%, parcial 30%, final 40%.
- Mostrar el estado de cada estudiante según su promedio.
- Buscar por nombre o código.
- Resumen del aula: total, aprobados, desaprobados y promedio general.

## Cómo ejecutarla

```bash
npm install
npm run dev
```

Luego abre en el navegador la dirección que muestra la consola (normalmente http://localhost:5173).
